# 烽火 十四年

《三國 逐鹿中原》引擎的第四款：1931～1945 年的十四年抗戰。人物、地名與事件取自公開史料；能力值、對話、地圖與介面皆為本作自行設計。

**原則**：語氣中性、以史實為本；屠殺等暴行只以文字帶過，不做成可操作的機制；日方由電腦控制、不能選，將領只用職稱、沒有頭像與列傳。

|---|---|---|
| 九一八事變 | 1931 | 東北淪陷、江橋抗戰、一二八淞滬、偽滿洲國、長征 |
| 長城抗戰 | 1933 | 熱河失守、喜峰口大刀隊、長征、一二九運動 |
| 西安事變 | 1936 | **抉擇**：和平解決（國共合作、張學良遭軟禁）或堅持兵諫 |
| 七七事變 | 1937 | 盧溝橋、淞滬、四行倉庫、平型關、南京失守 |
| 台兒莊與武漢 | 1938 | 台兒莊大捷、**花園口抉擇**（代價寫明）、武漢會戰、長沙大火 |
| 相持階段 | 1940 | 棗宜會戰（張自忠殉國）、百團大戰、皖南事變、珍珠港 |

每個劇本都會帶入開局之後的所有歷史事件，從任何年份開局都能一路玩到 1945 年 8 月日本投降。
全面抗戰（1937 年 7 月）以前，日軍只做局部侵略（東北、熱河、察哈爾）；之後電腦控制的中方勢力不會互相攻打。

## 特色規則

- **地圖 44 城**：含東北、臺灣（臺北、臺南）、沖繩、塞班、滇緬路（臘戌、列多）。臺灣海峽、東海是海路，中方要帶 20% 海軍才能渡海；日方掌握制海權。
- **日軍**：裝備優勢、本土增援、依年份的攻勢目標；**補給線**：佔領越多城戰力越低；1943 年起增援減半。
- **國共合作度**：每月下降，國共之間送禮可提高；50 以上同盟延續，25 以下同盟破裂，40 以下可能發生皖南事變。
- **游擊戰**：中共兩步以內的日佔城每月被削弱，中共也吸收新兵。
- **大後方遷移**：與日軍接壤的城，可以把商業、人口與一半的金遷往大後方（每城一次）。
- **美國參戰**：珍珠港事件後美軍行動（列多、塞班），每月援助國府金錢，1942 年起駝峰航線送來空軍。
- **日本投降**：1945 年 8 月，日方各城交還中國（臺灣光復），太平洋島嶼交給美軍；依握有城數評甲乙丙丁等。
