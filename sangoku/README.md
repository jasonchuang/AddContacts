# 群雄逐鹿（第一版原型）

原創的三國題材回合制策略遊戲。人物與城市取自公有領域的史實；能力值、公式、地圖與介面皆為本作自行設計。

## 怎麼玩

直接用瀏覽器打開 `sangoku/index.html`，不需要安裝或伺服器。

1. 選擇一位君主（9 個勢力，西元 190 年劇本）。
2. 點地圖上的城市，在右側對我方城市下指令。每位武將每月可行動一次。
3. 按「結束本月」，電腦勢力行動並進行每月結算。
4. 佔領全部 26 座城即統一天下。失去所有城市則遊戲結束。

## 指令

| 指令 | 說明 | 主要能力 |
|---|---|---|
| 開墾 / 商業 | 提升農業（秋收的糧）／商業（每月的金） | 政務 |
| 築城 | 提升城防（守城加成） | 統率 |
| 巡察 | 提升民心（影響收入與人口） | 魅力 |
| 訓練 | 提升部隊訓練度 | 統率 |
| 徵兵 | 金與人口換兵，新兵會稀釋訓練度 | 魅力（上限） |
| 搜索 | 發現城中的在野人才，或找到金 | 智略 |
| 登用 | 招攬已發現的在野人才或俘虜 | 魅力 |
| 賞賜 | 花金 100 提升忠誠（不消耗行動） | — |
| 移動 | 武將、兵、金、糧移到相鄰我方城市 | — |
| 出征 | 最多 3 名武將進攻相鄰城市，立即自動交戰 | 統率、武力、智略 |
| 俘虜 | 釋放或處斬俘虜 | — |

## 規則摘要

- 每月收入金（商業 × 民心），7 月秋收得糧（農業 × 民心），每月士兵消耗糧，缺糧會逃兵。
- 戰鬥最多 20 回合，戰力由兵數、主將統率、最高武力、訓練度決定，守方有城防加成。
  智略高可能發動計略，雙方都有猛將時可能單挑。
- 城破時守將可能逃往鄰近的己方城市，或被俘。君主有退路時必定逃脫。
- 存檔使用瀏覽器 localStorage：「存檔／讀檔」使用手動存檔欄，每月結束時另外自動存檔。

## 程式結構

```
sangoku/
  index.html      頁面
  style.css       樣式（含深色模式、手機版面）
  js/data.js      劇本資料（勢力、城市、道路、武將）
  js/engine.js    遊戲核心：狀態、指令、戰鬥、結算（不碰 DOM）
  js/ai.js        電腦勢力（透過與玩家相同的指令介面行動）
  js/ui.js        地圖、面板、指令視窗
  test/engine.test.js
```

執行測試：`node sangoku/test/engine.test.js`
