# 三國 逐鹿中原

原創的三國題材回合制策略遊戲。人物與城市取自公有領域的史實；能力值、公式、地圖與介面皆為本作自行設計。

## 下載與執行

- **最簡單**：下載 `sangoku/dist/qunxiong.html` 這一個檔案，用瀏覽器（Chrome、Edge、Safari）雙擊打開就能玩。
  所有程式與樣式都在這個檔案裡；連上網路時會載入書法字型，離線時改用系統字型。
- **開發用**：打開 `sangoku/index.html`（會讀取 `js/` 與 `style.css`）。
- 修改程式後重新打包單一檔案：`node sangoku/build.js`

## 怎麼玩

畫面採 90 年代策略遊戲的風格（原創）：像素地圖、深藍視窗、游標選單、軍師訊息。

1. 標題選「新遊戲」，先選劇本，再選君主與模式（**歷史劇本**：歷史事件依條件發生；**自由模式**：不發生歷史事件）。
   | 劇本 | 年份 | 看點（歷史模式的事件） |
   |---|---|---|
   | 群雄割據 | 190 | 反董卓聯盟、遷都長安、董卓之死、三顧茅廬… |
   | 宛城之戰 | 197 | 宛城之變（曹昂讓馬救父、典韋死守營門）、袁術稱帝、張繡再降 |
   | 官渡之戰 | 200 | 白馬斬顏良、千里尋兄、孫策遇刺、火燒烏巢、袁紹病逝 |
   | 烏巢之戰 | 200 | 許攸之計（抉擇：袁紹要不要留住許攸）、夜襲烏巢（抉擇：曹操信不信許攸）、張郃高覽倒戈、田豐之死 |
   | 赤壁之戰 | 208 | 孫劉同盟開局、苦肉計（蔣幹盜書）、火燒赤壁、平定荊南、鳳雛來投 |
   | 潼關之戰 | 211 | 割鬚棄袍、許褚裸衣鬥馬超、抹書間韓遂（同盟破裂）、渭南大捷 |
   | 漢中之戰 | 218 | 定軍山（黃忠斬夏侯淵）、趙雲空營計、雞肋（楊修之死、曹操退兵）、漢中王 |
   | 水淹七軍 | 219 | 水淹七軍（于禁降、龐德死）、白衣渡江、敗走麥城、曹操病逝 |
   | 夷陵之戰 | 221 | 魏蜀吳三國、劉備東征、火燒連營、白帝託孤 |
2. 在地圖上點選城市（或按 Tab 切換我方城市），從右下的選單下指令：
   - **內政**：開墾、商業、巡察、築城、訓練
   - **軍事**：徵兵（槍兵／騎兵／弩兵）、出征、移動
   - **人事**：搜索、登用、賞賜、處置俘虜
   - **外交**：同盟、停戰、宣戰、勸降（選對象、行動與使者，顯示成功率）
   - **情報**：城中武將、我方武將（可看列傳）、我方城市、勢力一覽（含外交關係）、記錄
   - **系統**：存檔、讀檔、音效、回到標題
3. 選「結束本月」，電腦勢力行動、每月結算；接著演出戰報與歷史事件，電腦勢力可能派使者提議同盟或停戰，
   軍師也會提醒糧食、敵情與人才。同盟與停戰中的勢力不能互相攻擊；攻擊中立勢力會自動開戰。
4. 佔領全部 26 座城即統一天下。

**操作**：方向鍵移動游標、Enter 決定、Esc 返回；滑鼠也可以直接點選。
出征與移動時用 ◀ ▶ 分配各兵種人數（Shift＋方向鍵每次 100）。

## 指令

| 指令 | 說明 | 主要能力 |
|---|---|---|
| 開墾 / 商業 | 提升農業（秋收的糧）／商業（每月的金） | 政務 |
| 築城 | 提升城防（守城加成） | 統率 |
| 巡察 | 提升民心（影響收入與人口） | 魅力 |
| 訓練 | 提升部隊訓練度 | 統率 |
| 徵兵 | 金與人口換兵，新兵會稀釋訓練度 | 魅力（上限） |
| 搜索 | 發現城中的在野人才，或找到金 | 智略 |
| 登用 | 招攬已發現的在野人才或俘虜 | 魅力 |
| 賞賜 | 花金 100 提升忠誠（不消耗行動） | — |
| 移動 | 武將、兵、金、糧移到相鄰我方城市 | — |
| 出征 | 最多 3 名武將進攻相鄰城市，立即自動交戰 | 統率、武力、智略 |
| 俘虜 | 釋放或處斬俘虜 | — |

## 規則摘要

- 兵種：槍兵、騎兵、弩兵，相剋為「槍剋騎、騎剋弩、弩剋槍」。騎兵進攻有衝鋒加成，弩兵守城有加成且首輪齊射，槍兵損失較少。
  每位武將對三種兵各有 S～C 適性，主將適性越高越強。徵兵時選兵種（槍兵最便宜、騎兵最貴）。
- 每月收入金（商業 × 民心），7 月秋收得糧（農業 × 民心）。士兵每月吃糧，另付軍餉（每 250 兵 1 金）；缺糧或欠餉都會逃兵。
  城市面板會顯示每月金收支（例：+74/月）與可徵兵上限（人口的 12%）。
- 戰鬥最多 20 回合，戰力由兵數、主將統率、最高武力、訓練度決定，守方有城防加成（城防滿 999 約 1.4 倍）。
  一城的兵通常打不下同等的城：先從鄰城「移動」集結兵力，再全力出征。
  智略高可能發動計略，雙方都有猛將時可能單挑。
- 城破時守將可能逃往鄰近的己方城市，或被俘。君主有退路時必定逃脫。
- 同盟為期 3 年，停戰 1 年，期滿恢復中立。
- 歷史事件會以場景演出（背景插圖、人物立繪、對話）；Enter 下一句、Esc 略過。
- 存檔使用瀏覽器 localStorage：「存檔／讀檔」使用手動存檔欄，每月結束時另外自動存檔。

## 程式結構

```
sangoku/
  index.html      頁面
  style.css       樣式（紙卷風介面，與 Godot 版一致）
  js/data.js      190 年劇本與地圖（勢力、城市、道路、武將）
  js/scenarios.js 其他五個名戰劇本（勢力配置、武將、初始外交、專屬事件）
  js/tuning.js    手感數值表（戰鬥、單挑、經濟、登用、難易度；意義見 SPEC.md）
  js/engine.js    遊戲核心：狀態、指令、戰鬥、結算（不碰 DOM）
  js/ai.js        電腦勢力（透過與玩家相同的指令介面行動）
  js/diplomacy.js 外交（同盟、停戰、宣戰、勸降、電腦提議）
  js/events.js    歷史事件（條件、效果、原創對話）
  js/icons.js     自繪 SVG 圖示（士兵、騎兵、旗幟、資源、指令）
  js/anime.js     動畫賽璐璐風武將肖像產生器（程式繪製，造型原創，與 Godot 版共用）
  js/portraits.js 肖像入口（優先用 portraits/ 插畫，否則用 anime.js）
  js/sound.js     晶片音樂風音效（WebAudio 即時合成，旋律原創）
  tools/build_font.py  重新產生像素字型子集（新增文字後執行）
  js/mapview.js   向量地圖（紙底、勢力領土、黃河長江、城池、圖例）
  js/ui.js        視窗與選單、標題、指令流程、軍師訊息、像素戰鬥
  fonts/          內文思源宋體 Noto Serif TC、標題霞鶩文楷 LXGW WenKai TC 子集（皆 OFL-1.1）
  build.js        打包成單一 HTML
  portraits/      武將插畫（<名>.jpg 半身像、<名>_head.jpg 頭像），build.js 會自動套用；沒有插畫的武將用程式繪製的肖像
  art/raw/        外部原圖（檔名＝武將名）與 crops.json（臉部位置）；執行 python3 sangoku/tools/import_portraits.py 轉成 portraits/
  art/ART_GUIDE.md  美術製作流程；art/portrait-briefs.md 為各武將繪製說明
  art/PUBLIC_DOMAIN_SOURCES.md  公有領域三國人物圖像（繡像）來源與使用注意事項
  tools/portrait-briefs.js  產生繪製說明
  dist/qunxiong.html  打包好的單檔版
  test/engine.test.js
  tools/playtest.js  自動試玩：讓 AI 代替玩家打完各劇本並統計（node sangoku/tools/playtest.js all 3 50）
  js/scenes.js    事件場景背景（10 種原創 SVG 插圖）
```

執行測試：`node sangoku/test/engine.test.js`
