# 新遊戲草案：民國兩部曲

兩款都沿用《三國 逐鹿中原》的引擎與介面（地圖、內政、戰鬥、外交、事件演出、手機版），換成近代中國的地圖、人物、劇本與規則。
人物與史事取自公開史料；能力值、外型、對話與規則皆為本作設計。人物立繪採原創畫風，不仿任何既有遊戲。

> 注意：這兩段是近代史，牽涉的人物、事件都還有在世的情感與爭議。建議遊戲語氣保持中性、以史實為本，
> 避免美化或醜化特定人物；屠殺等暴行以文字帶過、不做成可「操作」的遊戲機制。

---

## 一、《民國 群雄並起》（1916～1928）

袁世凱死後，北洋政府分裂，各地軍閥割據；最後國民革命軍北伐，蔣介石名義上統一中國。

### 勢力（依劇本出現）
| 勢力 | 首領 | 根據地 | 特色 |
|---|---|---|---|
| 北洋・皖系 | 段祺瑞 | 北京、安徽 | 控制中央政府，日本借款 |
| 北洋・直系 | 馮國璋 → 曹錕、吳佩孚 | 直隸、湖北 | 吳佩孚善戰 |
| 奉系 | 張作霖 → 張學良 | 東北三省 | 騎兵強、兵工廠 |
| 晉系 | 閻錫山 | 山西 | 守成穩固、「模範省」 |
| 國民黨（廣州） | 孫中山 → 蔣介石 | 廣東 | 黃埔軍校、北伐 |
| 桂系 | 陸榮廷 → 李宗仁、白崇禧 | 廣西 | |
| 西北軍 | 馮玉祥 | 陝甘、河南 | 「倒戈將軍」 |
| 滇系 | 唐繼堯 | 雲南 | |
| 川系 | 劉湘等 | 四川 | 內部分裂 |
| 孫傳芳 | 孫傳芳 | 江浙五省 | |

### 劇本
| 劇本 | 年份 | 看點 |
|---|---|---|
| 府院之爭 | 1917 | 張勳復辟（12 天）、段祺瑞再起、護法運動 |
| 直皖戰爭 | 1920 | 直系＋奉系對皖系 |
| 直奉大戰 | 1924 | 第二次直奉戰爭、**馮玉祥北京政變**（倒戈事件） |
| 國民革命軍北伐 | 1926 | 蔣介石誓師北伐、對吳佩孚、孫傳芳 |
| 東北易幟 | 1928 | 皇姑屯事件（張作霖遇害）→ 張學良選擇易幟歸順 → 統一 |

### 特色規則（提案）
- **倒戈**：軍閥部將忠誠低時可能整軍改投他方（馮玉祥式）。
- **外國借款**：向列強借款換金，但「外交依存」升高、民心下降。
- **黃埔軍校**：國民黨可培養新武將（每年畢業一批）。
- **兵工廠**：漢陽、瀋陽、太原等城可生產新式步槍，提升戰力。
- **兵種**：步兵、騎兵、炮兵（取代槍、騎、弩）。
- **結局**：統一全國或依史實「東北易幟」完成北伐。

## 二、《烽火 抗戰八年》（1935～1945）

國共內戰與日本侵華交織；最後日本戰敗投降。

### 勢力
| 勢力 | 首領 | 根據地 | 特色 |
|---|---|---|---|
| 國民政府 | 蔣介石 | 南京 → 重慶 | 正規軍最多、德式師 |
| 中共 | 毛澤東 | 陝北延安 | 游擊戰、敵後根據地 |
| 日本（關東軍／華北方面軍） | 由電腦控制 | 東北、華北 | 裝備精良、空軍與海軍 |
| 晉綏軍 | 閻錫山 | 山西 | |
| 西北軍／東北軍 | 張學良、楊虎城 | 西安 | 西安事變 |
| 桂系 | 李宗仁、白崇禧 | 廣西 | 台兒莊 |
| 汪精衛政權 | 汪精衛 | 南京（1940 起） | 事件產生 |

### 劇本
| 劇本 | 年份 | 看點 |
|---|---|---|
| 西安事變 | 1936 | 張學良、楊虎城兵諫 → **抉擇**：第二次國共合作 |
| 七七事變 | 1937 | 盧溝橋、淞滬會戰、南京失守（以文字帶過） |
| 台兒莊與武漢 | 1938 | 台兒莊大捷、黃河決堤（抉擇）、武漢會戰 |
| 相持階段 | 1940 | 百團大戰、汪精衛政權、皖南事變 |
| 反攻 | 1944 | 豫湘桂、滇緬反攻、**日本投降（1945 年 8 月結局）** |

### 特色規則（提案）
- **國共合作度**：合作高時兩方不互攻、共同抗日；低時摩擦（可能爆發皖南事變類事件）。
- **游擊戰**：中共部隊可在日軍佔領城的周邊截斷補給（沿用楚漢的「截斷糧道」）。
- **大後方遷移**：國府可把工廠與人口遷往重慶、昆明。
- **外援**：美國援助（駝峰航線、飛虎隊）從 1941 年後開始，提供金與空軍加成。
- **日軍**：由電腦控制、戰力高但補給線長；佔領越多城補給越吃緊。
- **兵種**：步兵、機械化（坦克／炮）、空軍支援。
- **結局**：撐到 1945 年 8 月日本投降即勝利；依收復城數評分。

### 主要人物（約 60 位）
國府：蔣介石、宋美齡、陳誠、薛岳、張自忠、孫立人、杜聿明、衛立煌、戴笠、何應欽、白崇禧、李宗仁、湯恩伯……
中共：毛澤東、周恩來、朱德、彭德懷、劉伯承、林彪、賀龍、聶榮臻……
其他：張學良、楊虎城、閻錫山、汪精衛、史迪威、陳納德……
日方將領可只用職稱（例：「華北方面軍司令官」），避免為侵略方塑造英雄形象。

## 建議做法

1. **先做《民國 群雄並起》**：規則和三國最接近（軍閥割據、統一天下），改動少、風險低。
2. 《烽火 抗戰八年》多了「第三方電腦勢力（日本）」「國共合作度」「外援」等新機制，工程較大，第二個做。
3. 兩款共用一張「近代中國」地圖（約 35 座城：北京、天津、瀋陽、太原、西安、延安、南京、上海、武漢、長沙、廣州、重慶、成都、昆明……），
   加上鐵路線作為道路。
4. 素材：武將頭像、事件背景、兵種圖都需要新畫（民國軍裝、步槍、火炮），提示詞我會先準備好。
