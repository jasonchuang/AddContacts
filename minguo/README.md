# 民國 群雄並起

《三國 逐鹿中原》的姊妹作：1915～1928 年，從袁世凱稱帝、護國戰爭，到北洋分裂、各地軍閥割據，直到國民革命軍北伐、東北易幟。
人物、地名與事件取自公開史料；能力值、對話、地圖與介面皆為本作自行設計，語氣保持中性。

- 單檔版：`node minguo/build.js` → `minguo/dist/minguo.html`
- 測試：`node minguo/test/engine.test.js`、`node minguo/test/e2e.test.js`

## 兵種

| 兵種 | 特色 | 哪裡能徵 |
|---|---|---|
| 步兵 | 便宜耐打，剋制砲兵 | 每座城 |
| 坦克 | 攻擊最強、開戰衝鋒，剋制步兵 | 兵工廠城：瀋陽、武漢、太原、上海、南京 |
| 砲兵 | 開戰砲擊、削減城防，剋制坦克 | 每座城 |
| 空軍 | 開戰轟炸、不受剋制，冬季減半 | 機場城：北京、瀋陽、南京、廣州 |
| 海軍 | 攻守港口城時艦砲支援 | 港口城：天津、青島、上海、福州、廣州、南京、武漢 |
