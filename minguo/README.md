# 民國 群雄並起

《三國 逐鹿中原》的姊妹作：1916～1928 年，袁世凱死後北洋分裂、各地軍閥割據，直到國民革命軍北伐、東北易幟。
人物、地名與事件取自公開史料；能力值、對話、地圖與介面皆為本作自行設計，語氣保持中性。

## 執行

- 線上預覽：GitHub Pages 的 `/minguo/preview/`
- 單檔版：`node minguo/build.js` → `minguo/dist/minguo.html`
- 測試：`node minguo/test/engine.test.js`、`node minguo/test/e2e.test.js`

## 劇本

| 劇本 | 年份 | 看點 |
|---|---|---|
| 府院之爭 | 1917 | 張勳復辟、段祺瑞「武力統一」 |
| 直皖戰爭 | 1920 | 直系＋奉系對皖系、粵軍回師廣州 |
| 直奉大戰 | 1924 | 山海關之戰、馮玉祥北京政變、孫中山病逝 |
| 國民革命軍北伐 | 1926 | 誓師北伐、汀泗橋、龍潭之戰 |
| 東北易幟 | 1928 | 皇姑屯事件、張學良的抉擇 |

## 兵種

步兵（步槍、刺刀）、騎兵（馬槍、馬刀）、炮兵（野戰炮）；相剋：步剋騎、騎剋炮、炮剋步。
