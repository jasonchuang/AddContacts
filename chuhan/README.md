# 楚漢相爭

秦末楚漢之際的原創歷史策略遊戲。以《三國 逐鹿中原》的引擎為基礎（地圖、內政、戰鬥、單挑、外交、官職、事件場景、手機版），
換成楚漢時代的地圖、人物與劇本，並加入「特技」系統。

## 怎麼玩
- 打包：`node chuhan/build.js` → 用瀏覽器打開 `chuhan/dist/chuhan.html`。
- 開新遊戲先選劇本，再選君主與模式（歷史劇本會發生史實事件，自由模式不會）。
- 年份以「前206年」顯示，逐年遞減到前202年……

## 劇本
| 劇本 | 年份 | 看點 |
|---|---|---|
| 漢王之國 | 前206年4月 | 鴻門宴回憶、蕭何薦韓信「國士無雙」拜將、八月暗渡陳倉、三秦（雍・塞・翟）擋路、彭城之戰 |
| 韓信北伐 | 前205年8月 | 韓信橫掃北方：木罌渡河（魏）→ 背水一戰（趙）→ 師事廣武君 → 燕國歸降 → 濰水之戰（齊、龍且戰死）→ 假齊王 → 四面楚歌 |
| 垓下之戰 | 前202年12月 | 十面埋伏、四面楚歌、霸王別姬；**烏江抉擇**：玩家扮演楚時可選「渡江・捲土重來」或「自刎烏江」。韓信、彭越、英布是漢的封王，可能自立 |

## 楚漢特色規則
| 規則 | 在哪裡 | 說明 |
|---|---|---|
| 截斷糧道 | 軍事 → 襲擾（金 100） | 派武將燒毀相鄰敵城軍糧、民心下降、守軍逃散；武力高較不易被擒，彭越（游擊）燒得更多更安全。電腦的游擊將領也會這麼做 |
| 封王 | 人事 → 封王 | 把城封給部下：忠誠全滿、兼任太守；但野心 80 以上的王忠誠每月 -1，低於 60 時可能據城自立（城中忠誠低的武將會跟隨） |
| 反間計 | 人事 → 反間（金 300） | 離間敵將：成功時忠誠 -35、軍師被罷免，忠誠太低就離開。陳平（奇計）成功率高；范增被離間到底會「背疽發作而死」 |
| 手動指揮戰鬥 | 出征時 | 每段下令：一般、突擊、穩守、計略、單挑、撤退（與三國版相同） |

## 韓信
- 統率 100、武力 86、智略 98，三種兵種適性都是 S。
- 特技「兵仙」：進攻戰力 ×1.3、守城 ×1.15；**兵力少於敵軍時再 ×1.25（背水一戰）**；計略發動率提高。
- 測試中，同樣兵力攻城，韓信的勝率遠高於一般將領。

## 特技
| 特技 | 武將 | 效果 |
|---|---|---|
| 兵仙 | 韓信 | 進攻 ×1.3、守城 ×1.15、劣勢時背水一戰 ×1.25、計略率提高 |
| 霸王 | 項羽 | 進攻 ×1.3、守城 ×1.1、單挑武力 +8 |
| 運籌 | 張良 | 計略率大幅提高（擔任軍師時全軍適用） |
| 奇計／亞父／廣武 | 陳平／范增／李左車 | 計略率提高（李左車守城 ×1.15） |
| 鎮國 | 蕭何 | 擔任太守時收入大增 |
| 游擊／黥布／鴻門／名將／義士 | 彭越／英布／樊噲／章邯／田橫 | 各種攻守或單挑加成 |

軍師開局即任命：漢 張良、西楚 范增、趙 李左車。

另有背景音樂（五聲音階原創配樂）與事件語音（瀏覽器內建朗讀），可在系統選單開關。

## 檔案
```
  js/data.js       地圖（28 城）、人物能力、兵種適性、特技、外觀
  js/scenarios.js  兩個劇本與專屬事件
  js/engine.js     規則（新增特技與西元前年份）
  其餘與《三國 逐鹿中原》相同：ai.js、diplomacy.js、events.js、ui.js、mapview.js、scenes.js…
  test/engine.test.js   測試（node chuhan/test/engine.test.js）
  tools/playtest.js     自動試玩（node chuhan/tools/playtest.js all 3 50）
```

## 自動試玩（每個勢力 3 局、最多 50 年）
- 韓信北伐：漢 3/3 統一（平均約 26 年）；魏、代約 1 年內滅亡，燕約 3.6 年，趙約 6 年，齊約 12 年。
- 漢王之國：漢 1/3 統一；三秦約 2–3 年內被攻滅。

人物與地名取自《史記》《漢書》等公有領域史料；能力值、兵力、對話與美術皆為本作原創。
