# 戰國 七雄爭霸

戰國末期（前 260～前 221 年）秦統一六國的原創歷史策略遊戲。使用與《三國 逐鹿中原》、《楚漢相爭》相同的引擎與介面。
人物、地名與事件取自《史記》《戰國策》等公有領域史料；能力值、外型、對話與規則都是本作自行設計，與任何漫畫、動畫或遊戲作品無關。

## 怎麼玩
- 打包：`node zhanguo/build.js` → 單檔版 `zhanguo/dist/zhanguo.html`，預覽版 `docs/zhanguo/preview/`。
- 開新遊戲先選劇本，再選君主、模式（歷史劇本會發生史實事件與抉擇）與難易度。
- 年份以「前260年」顯示，逐年遞減。

## 特色規則
| 規則 | 指令 | 說明 |
|---|---|---|
| 截斷糧道 | 襲擾（金 100） | 燒毀相鄰敵城軍糧、民心下降、守軍逃散 |
| 封君 | 封君 | 把城封給部下（如武安君、信陵君）：忠誠全滿、兼任太守；野心大的封君可能自立 |
| 反間計 | 反間（金 300） | 離間敵將（如郭開讒害李牧）；頓弱（奇計）成功率高 |
| 合縱 | 歷史事件 | 五國聯軍同時對秦開戰 |
