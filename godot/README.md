# 群雄逐鹿（Godot 4 版）

城市為核心的回合制三國策略遊戲。玩法類型參考經典三國策略遊戲（城市指令、武將管理、回合制、勢力擴張），
但規則數值、事件文字、地圖與美術皆為本作原創；人物與城市取自公有領域的史實。

## 需求

- [Godot 4.3](https://godotengine.org/download)（標準版即可，不需要 .NET 版）

## 開啟與遊玩

1. 開啟 Godot，選「匯入」，指向本資料夾的 `project.godot`。
2. 按右上角 ▶（或 F5）執行。

也可以用指令列直接執行：

```bash
godot --path godot
```

## 執行測試

```bash
godot --headless --path godot --import                               # 第一次需要匯入專案
godot --headless --path godot --script res://tests/run_tests.gd      # 執行核心規則測試
```

測試涵蓋：劇本規模（30 城、6 勢力、100 武將、20 事件、5 兵種）、各項指令、兵種相剋、水路水軍、
外交（同盟、停戰、宣戰、勸降）、歷史事件觸發、君主繼承、存讀檔可重現、肖像產生，以及全 AI 十年模擬。

## 遊戲系統（6 個模組）

| 模組 | 內容 |
|---|---|
| 世界地圖 | 30 座城、道路（含 11 條水路）、黃河長江、山脈；勢力領土上色 |
| 內政 | 開墾、商業、治安、築城、訓練；人口成長、秋收、缺糧逃兵；太守每月自動開發 |
| 武將 | 搜尋、登用、賞賜、任命太守與軍師、忠誠（過低會出奔）、俘虜處置、君主繼承 |
| 軍事 | 徵兵（5 兵種）、分兵種調兵與出征、攻城、守城 |
| 外交 | 同盟、停戰、宣戰、勸降；電腦勢力也會向玩家提議同盟或停戰 |
| 戰爭 | 依武將能力、兵力、兵種相剋、適性、城防、水路自動結算，附戰鬥動畫 |

### 兵種

| 兵種 | 每千兵 | 特性 |
|---|---|---|
| 步兵 | 金 80 | 攻守均衡，守城加成 |
| 槍兵 | 金 100 | 損失較少，剋制騎兵 |
| 騎兵 | 金 200 | 進攻衝鋒，剋制弓兵 |
| 弓兵 | 金 120 | 開戰齊射，剋制槍兵 |
| 水軍 | 金 150 | 沿水路作戰極強，陸戰較弱 |

每位武將對 5 種兵各有 S～C 適性（例如趙雲槍兵 S、馬超騎兵 S、黃忠弓兵 S、周瑜水軍 S）。

### 劇本模式

- **歷史劇本**：20 個事件依條件觸發，例如反董卓聯盟、遷都長安、董卓之死、三顧茅廬、官渡對峙、孫劉同盟。
- **自由模式**：不發生歷史事件（仍有蝗災、豐年等隨機事件），各勢力自由發展。

## 畫面

1. **標題**：新遊戲（選君主與模式）、讀取存檔
2. **世界地圖**：點擊城市進入城市管理；可進攻的城上方有紅色叉號
3. **城市管理**：右側面板，資源、兵種組成、發展度、武將、指令
4. **武將管理**：上方「武將」按鈕，所有武將的能力、忠誠、所在城、職位，任命軍師
5. **戰爭**：出征或被攻擊時播放戰鬥畫面
6. **歷史事件／外交**：事件對話、外交提案；上方「外交」按鈕可出使各勢力

## 專案結構

```
godot/
  project.godot
  data/scenario_190.json      劇本資料（由 tools/gen_data.js 產生）
  scenes/main.tscn            主場景（介面由程式建立）
  scripts/game.gd             autoload：遊戲狀態、指令轉送、UI 佇列
  scripts/core/               遊戲規則（不依賴畫面，可單獨測試）
    rules.gd                  兵種、相剋、內政指令常數
    world.gd                  狀態查詢、兵力、易主、勢力滅亡與繼承
    engine.gd                 城市指令、每月結算、忠誠
    battle.gd                 簡化戰鬥
    diplomacy.gd              外交
    events.gd                 歷史事件條件與效果
    ai.gd                     電腦勢力
    turn.gd                   回合流程
    loader.gd / save.gd       讀劇本、存讀檔（JSON）
    portrait.gd / icons.gd    Q 版肖像、兵種圖示（程式產生的原創 SVG）
  scripts/ui/                 介面
  tests/run_tests.gd          headless 測試
  tools/gen_data.js           產生與檢查劇本資料（node godot/tools/gen_data.js）
  art/portraits/              放武將插畫（檔名＝武將名.png），有圖就自動取代程式肖像
```

## 修改資料

劇本資料由 `tools/gen_data.js` 產生，修改武將、城市、事件後執行：

```bash
node godot/tools/gen_data.js
```

腳本會檢查數量（30 城、6 勢力、100 武將、20 事件）、引用是否存在、地圖是否連通。

## 匯出

在 Godot「專案 → 匯出」新增 Windows / macOS 預設，並在「資源」分頁的「要匯出的非資源檔」填入 `*.json`，
確保劇本資料會一起打包。

## 存檔位置

`user://saves/`：
- Windows：`%APPDATA%\Godot\app_userdata\群雄逐鹿\saves`
- macOS：`~/Library/Application Support/Godot/app_userdata/群雄逐鹿/saves`

每月結束時自動存到「自動存檔」，另有 3 個手動存檔欄。
